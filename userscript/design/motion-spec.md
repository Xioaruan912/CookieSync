# CookieSync 油猴版动效规格

- S1 使用一次约 180ms 的不透明度和位移动画。焦点、表单和导航随面板立即可用。
- S2 使用 220ms 的导航指示条 transform 过渡。反向切换和连续切换从当下位置移动。内容区统一使用原生滚动，导航与操作栏留在各自布局轨道。
- S3 在真实同步开始时运行一轮双向路径脉冲，两股光点交错启动，结果到达时立即移除。脉冲不代表服务端进度。状态由文本表达，失败提供重试机会。
- 减少动态效果下关闭时间过渡，保留全部状态。桌面图形与状态并排，窄屏图形位于主按钮下方。面板关闭后浏览器清理动效。此面板只需原生滚动和少量 CSS 动效。

## v1.7 路线与反馈

居中箭头表明双向合并，文字表达实际同步结果。沿用 680ms 双向信号，返程比去程延后 120ms，两者重叠。信号只在指针触发的真实请求期间运行一轮；快速完成可以直接到结果，慢请求也不会被误读为进度。最近时间独立显示，精确到分钟。小型面板使用现有 CSS 与原生滚动，不增加页面动效依赖。
