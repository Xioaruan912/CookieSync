# CookieSync 油猴版视觉方向

2026-11-22 在 Chromium 的 1440 × 900 视口观察两个公开参考，查看首屏并用滚轮进入后续内容。

- Apple AirPods Pro 将首屏焦点集中于单个主体，向下滚动后以独立标题切换观察尺度。面板借鉴主体优先和段落节奏，主体是同步状态。 [参考页面](https://www.apple.com/airpods-pro/)
- Linear 将主文案和示意图拆成平行层级，滚入产品介绍后，用对齐的几何线条解释功能。面板借鉴信息和示意的分工。 [参考页面](https://linear.app/)

| 方向 | 构图、字与空间 | 配色与素材 | 使用感受 |
|---|---|---|---|
| 同步路径 | 结果和操作居左，本机与 WebDAV 的示意居右。宽屏分栏，窄屏堆叠 | 浅暖纸面、深蓝状态区，CSS 绘制端点和线路 | 迅速确认状态和去向 |
| 状态档案 | 单列展示结果、目的地和规则。用紧凑对齐和时间层级强化信息 | 暖白和青绿，完全用文字与细分隔线 | 稳定且密度较高 |
| 步骤引导 | 连接、同步和复核按操作顺序排列，主按钮跟随当前步骤 | 暖灰底和少量蓝，使用简洁的步骤节点 | 对新用户友好，每日访问路径更长 |

采用同步路径。首次配置继续直达 WebDAV，已配置用户打开即见结果。保留四个栏目、原有状态和独立脚本结构。线路由本机状态驱动，素材均为面板组件和 CSS。

## v1.6 概览重构

比较了三种构图。**沉浸式舞台**用通栏深色空间展示同步状态与两端设备，桌面文字和剪影并排，移动先显示状态和按钮。**白底产品肖像**可以放大设备，但会压过同步反馈。**逐步滚动揭示**更适合长产品页，用户需要滚动才能操作。采用沉浸式舞台。延用参考中单一主角、场景级对比和简洁的操作层级。所有设备图形使用本地 CSS 绘制。

## v1.7 浅色双栏概览

在 Chromium 1440 × 900 实际滚动 Apple AirPods Pro 3 与 Linear 首页。AirPods 用大面积浅底与留白托住两个主体，下滚后用标题切换内容尺度。Linear 用暗色与低噪背景把重心交给文字和产品。分别借鉴主体优先和表面分层，保留 CookieSync 的短任务路径。没有复用外部素材。

| 原型 | 视觉主角与构图 | 素材、配色与取舍 |
|---|---|---|
| 浅色双栏 | 左侧同步结果，右侧本机与 WebDAV 路线，下方一排连接事实 | 雾紫、深墨色文字、原创 CSS 图形。390px 将主按钮放在图形前，左对齐便于扫读。 |
| 深绿居中 | 状态居中，路线整行，连接事实在独立区域 | 深绿状态底与浅色控制。视觉更集中，但桌面使用纵向空间更多，日常操作视觉权重偏重。 |

以同步状态、操作按钮和连接事实为共同场景，在 1440px 与 390px 实际截图对比两套原型，选浅色双栏。正式面板保留统一的色彩、系统中文字体、可见焦点和 44px 主要控制。图形用 CSS 绘制，减少占用，避免脚本额外请求字体或素材。
