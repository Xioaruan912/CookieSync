# 自动同步网站名单

1.9.0 默认启用精选 300 条网站规则，涵盖日常社交、视频、购物、网盘、社区、开发、学习等用途。这是便利名单，不是流量排名；同一平台的不同服务可能各有条目。域名可能迁移，用户可自行补充；不保证每个站点能恢复跨设备登录。

## 使用

在设置 → 自动同步网站名单中添加域名或网址，搜索并勾选／取消内置站点。根域名匹配它自己和子域名，绝不按字符串片段匹配；更具体的规则优先。例如允许 `example.com`、关闭 `private.example.com`，只会停用该子域。现有同步管理里的推送／拉取关闭开关仍优先。

名单外的网站不会自动登记、采集、推送或恢复，升级前已登记的站点和待传队列也会暂停；本地及云端已有数据保留。手动推送／拉取不受此名单限制。勾回或添加域名可恢复自动处理。发现开关只控制新站点发现；后台自动同步和启动拉取开关继续各自生效。

名单覆盖配置随同扩展身份的 Chrome 账号同步，已连接 Google Drive 后也随自动检查同步到独立 `CookieSync-sites-v1.json`。Chrome 同步必须开启浏览器配置同步，Drive 每台电脑需分别授权。该配置只含域名、允许／关闭、修改时间与版本标识，不含 Cookie 或密码，不另行加密。独立规则最多 400 条（包括关闭记录）；内置目录不占 Chrome 同步存储配额。不同域名的修改合并，同一域名较新版本优先，关闭记录保留以免旧设备重新启用。

无法可靠识别登录状态；名单内未登录站点也可能有 Cookie / LocalStorage。请仅同步自己的账号，按需停用站点并启用登录数据加密。
